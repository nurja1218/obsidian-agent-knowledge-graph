# 코드 인라인 마커 컨벤션 (@MX) — 글로벌

MoAI-ADK `@MX` 태그를 **이름 그대로(verbatim)** 채택한 경량 코드 마커. 프로젝트 무관 공통 규약.
목적: 에이전트·리뷰어에게 **"이 라인이 왜 위험/중요한지"** 를 코드 옆에서 즉시 전달.

> **MoAI 는 설치하지 않는다** — 어휘(@MX 태그명)만 공유. 스캐너·워크플로우는 내 커스텀 셋업을 쓴다.
> 각 마커의 *사유 1줄*이 최종 진실이다 (태그 분류가 아니라).

## ⛔ 남용 금지 (최우선)

**"가장 위험하고 중요한 코드만"** 표시한다. 흔해지면 노이즈가 되어 아무도 안 본다.
- 평범한 CRUD·getter·단순 매핑에 붙이지 말 것
- 한 파일에 3~4개 넘으면 과다 — 정말 위험 밀집 지점인지 재고
- 새 태그 종류 임의 추가 금지 (아래 4종 닫힌 집합만)

## 마커 4종 (MoAI @MX 닫힌 집합)

주석 스타일은 기존 코드 그대로. `@MX:` prefix + 사유 1줄. `grep -rn "@MX:"` 로 수집 가능해야 함.

| 태그 | 언제 | 예 |
|------|------|-----|
| `@MX:ANCHOR` | 중요 계약 / 다지점 동기화 (fan-in ≥ 3, 한 곳만 고치면 깨지는 곳) | 캐시↔SoR 이중쓰기, 여러 호출자가 의존하는 공용 계약 |
| `@MX:WARN` | 위험 영역 (동시성, 분산/네트워크 경계, 인지 복잡도 ≥ 15) | race, fire-and-forget, 원격 왕복, 부분 실패 |
| `@MX:NOTE` | 비자명 컨텍스트 (매직값·비즈니스 규칙) — **남용 1순위, 정말 비자명할 때만** | 임계값 근거, 외부 계약 강제값 |
| `@MX:TODO` | 미완 / 커버 누락 (후속 티켓 번호 필수) | 테스트 없는 분기, 임시 우회 |

```ts
// @MX:ANCHOR 캐시와 SoR 양쪽 동기화 필수 — 한쪽만 고치면 정합성 깨짐
// @MX:WARN 원격 write 왕복 — 응답 경로 밖으로 분리 검토
// @MX:NOTE 300 = 외부 API 문장분리 상한, 초과 시 강제 flush
// @MX:TODO 재연결 실패 경로 테스트 없음 — TICKET-123 후속
```

## 프로젝트별 앵커

이 파일은 **generic 규약**. 각 프로젝트는 자기 repo `.claude/rules/` 에 **프로젝트 BLOCKER 에 매핑한 앵커 rule** 을 두고 이 글로벌 규약을 참조한다.
- 예: `.claude/rules/12-inline-risk-markers.md` — ANCHOR = 캐시↔원본 DB 변환기, WARN = 전 리전 fan-out 발행

## 체크리스트

- [ ] `@MX:ANCHOR` 는 짝 지점도 함께 처리했나
